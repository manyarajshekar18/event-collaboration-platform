# 🎉 Event Collaboration Platform

## 📌 Project Overview
This is a full-stack web application where **Organizers** and **Service Providers** collaborate to manage events efficiently.

---

## 🚀 Features

### 👤 Organizer
- Create and manage events
- View applications from providers
- Chat with providers

### 👷 Provider
- Browse events
- Apply for events with proposal & budget
- Chat with organizers

### 💬 Chat System
- Event-based messaging
- Only participants can communicate

---

## 🛠️ Technologies Used

### Frontend
- React.js
- Tailwind CSS

### Backend
- Node.js
- Express.js

### Database
- MongoDB Atlas

### Authentication
- JWT (JSON Web Token)

---

## 🔗 How It Works

1. User logs in (Organizer / Provider)
2. Organizer creates event
3. Provider applies for event
4. Both communicate using chat
5. Notifications are triggered for actions
